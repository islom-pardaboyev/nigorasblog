# Adabiyot Dunyosi

Sof React + Vite + Tailwind CSS loyihasi. Vercel uchun tayyor.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel'ga deploy

1. Loyihani GitHub'ga push qiling.
2. vercel.com da "New Project" → repository tanlang → Deploy.

`vercel.json` SPA routing'ni hal qiladi, `HashRouter` esa refresh'da 404 chiqmasligini ta'minlaydi.
